## Software estimation, with evidence

CoBRA is a local-first workspace for reproducible effort estimation, Japanese market benchmarks, and analysis of AI adoption across engineering phases.

The experiment explores a simple question: how can estimation become easier to inspect, explain, and repeat?

## Explore the project

The source repository contains the implementation and its own documentation. Visit the repository for current capabilities, setup instructions, and project history.
